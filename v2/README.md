# SAMA Insurance — V2

Independent second design for the client presentation. V1 was not modified.

## Local preview

Run `npm run dev` inside this folder. Open http://127.0.0.1:4322/.

## Production files

Run `npm run build`. The complete static site is generated in `dist/`.
Run `npm run preview` to preview the build.

## Included

- New homepage and visual system using the original SAMA logo
- Searchable catalogue with five categories and all 27 original offerings
- 27 individual product pages with preparation checklists and related services
- Enquiry presentation flow with service preselection and contact preferences
- Responsive navigation, expandable FAQs, accessible form labels and reduced-motion support

The enquiry form is explicitly a demo: it neither transmits nor stores entries. Configure verified business contact details, a delivery service and the final privacy policy before live lead collection. No placeholder contact numbers, licence numbers or fabricated testimonials have been published.
