# SAMA Insurance — V3

Independent third design for the client presentation. Created entirely in V3. V1 and V2 remain unchanged.

## Preview

Run `npm run dev` in this folder and open http://127.0.0.1:4323/.

## Build

Run `npm run build` to generate the complete static website in `dist/`.
Run `npm run preview` to preview the production build.

## Design

A bold, youth-oriented direction with the original SAMA logo, vivid red and navy, lime accents, oversized Poppins typography, original lifestyle photography, rounded product tiles and reduced-motion support.

Includes the homepage, searchable catalogue, all 27 original product offerings with individual pages and icons, service-linked enquiry demo and privacy page. The homepage previews eight services; category filters and search access the full catalogue.

The enquiry form is a presentation demo. It neither sends nor stores personal information. Connect a verified business contact channel and update the final privacy policy before collecting live enquiries.

Hero photograph generated specifically for this version. Logo and product catalogue retained from the previous versions.
