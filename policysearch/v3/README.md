# Sama v3 — A Day Worth Protecting

A continuous illustrated day for Sama Insurance Brokers. The custom SVG neighbourhood, draggable sun, changing daylight and time-based coverage notes create the main navigation through the story. No icon library is used.

## Run

```sh
npm install
npm run dev
```

Preview: http://localhost:3002

```sh
npm run build
```

This workspace reuses `../v1/node_modules` through a symlink. For a separate checkout, omit the symlink and install dependencies normally. Typography uses Google Fonts with system fallbacks. The site's insurance categories, motor quote destination and contact details are preserved.
